    Summary

    Note: This site does not have an SSL certificate, so your browser may show a "Connection is not secure" warning. A login is required to use this web application. I contributed to this project by working with the lead developer, developing pages and creating database tables as needed.

    Features

    • Dashboard pages for Veritas Academy consultants
    • Tracking students' applications to schools abroad
    • Tracking students' to-do lists
    • Tracking students' application progress
    • Creating, editing and listing data for the consultants' business needs

    Development Process

    On the Front-End part, all pages are built as .cshtml views with classic HTML, CSS and JavaScript. I contributed to several pages and added page content using small-scale REST API calls with AJAX.

    On the Back-End part, the project uses the standard ASP.NET MVC 5 model-view-controller template, and most of the controllers and pages are scaffolded with Entity Framework. My contributions were controller actions that act as API endpoints, returning JSON responses for JavaScript AJAX calls. I also used ADO.NET in some of these actions.
