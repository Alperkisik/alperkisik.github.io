    Summary

    Features

    • Information pages about municipalities in Türkiye
    • Each municipality is shown with its mayor and the mayor's political party
    • Every citizen can sign up with their national identification number
    • Members can view all municipalities but can only interact with the municipality where they live
    • Main features for members:
      • Posting complaints about a municipality's services
      • Posting praise for a municipality's services
      • Direct messaging with municipalities and other members
      • Tracking municipalities' services
    • A mobile application with the same features
